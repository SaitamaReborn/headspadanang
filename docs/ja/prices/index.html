よくある質問

ダナンのヘッドスパはいくらですか？

ハーブシャンプー25分が約12万ドン（約700円）から。45分のヘッドスパは約25万、肩・首を含む60分は約38万、90–105分のシグネチャーコースは60万–85万ドンです。

ベトナム式シャンプー（ゴイダウ）とは？

ソープナッツ、ザボンの皮、レモングラスを煮出した液で洗髪し、頭皮と首・肩のマッサージを組み合わせたベトナムの伝統ケアです。韓国式より短く手頃です。

ベトナム式と韓国式、どちらを選ぶべき？

時間で選ぶのがコツです。ベトナム式は25–45分でハーブと手技が中心。韓国式は60–105分で頭皮診断・スチーム・トリートメントが入り、料金は2〜3倍です。

予約は必要ですか？

平日の基本シャンプーは飛び込みで大丈夫です。60分以上のコース、夜の時間帯、週末は前日予約をおすすめします。
